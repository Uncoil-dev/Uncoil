# Quick-start templates

Copy one file into your project, set `UNCOIL_API_KEY`, and run it.

| File | What it shows |
| --- | --- |
| `openai_agent.py` | An OpenAI chat call with one tool, traced end to end |
| `anthropic_agent.py` | The same with Anthropic |
| `langgraph_agent.py` | A small LangGraph graph |
| `private_by_default.py` | Sampling and redaction turned on |
