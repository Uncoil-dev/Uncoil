HANDOFF NOTES

Logo: Recreated from the site's canonical BrandLogo component — lowercase "uncoil" set in Geist Pixel with the rotated acid-yellow highlight mark behind it, not redrawn from memory.

Type: Geist Pixel for the wordmark and the one primary headline (site's h1 treatment); Geist Mono for labels, the CTA, and the code panel; Georgia for the founder's own words. Production email should keep Georgia/system-mono fallbacks — most inboxes strip custom web fonts, so Geist Pixel/Mono are a "nice if it loads" enhancement, not something to rely on.

Color: Paper #ECEAE3, white card #FFFFFF, near-black text, pure black rules/panel, acid yellow reserved for the highlight mark, code-panel labels and the single CTA.

Structure: One primary CTA (send your first trace) stays visually dominant; the coding-agent panel and "book a fit call" are intentionally smaller and quieter so they don't compete.

Responsive: Single-column throughout; mobile trims padding and type modestly and the CTA goes full-width for an easy tap target. No images used, so the design is unaffected by images-off settings.
