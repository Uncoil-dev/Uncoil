HANDOFF NOTES

Type: Headlines, labels and the CTA use a monospace stack ('Courier New', Courier, monospace) to read as technical documentation. Greeting, body copy and the invitation use Georgia for the founder-note warmth. No web fonts — both stacks are email-safe.

Color: Paper background #ECEAE3, white content card #FFFFFF, near-black text #111–#222, pure black #000 for rules/wordmark/proof panel, acid yellow #F4D44D reserved for the panel label, trace indices and the CTA. No gradients, no blue.

Spacing: 600px max card width, 40px desktop / 22px mobile side padding, generous vertical rhythm between blocks (16–34px) so the note breathes rather than feels packed.

Responsive: Single-column table layout throughout. On mobile, type scales down modestly (headline 34px → 25px) and the CTA becomes full-width for an easy tap target (>44px tall). No side-by-side columns at any width.

Images: None used anywhere in the design — it renders identically with images disabled in the client.
